COMO TESTAR NO VS CODE
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Instale a extensão Live Server.
4. Clique com o botão direito em index.html.
5. Escolha Open with Live Server.

GITHUB PAGES
Envie TODOS os arquivos diretamente para a raiz do repositório.
Não envie o ZIP e não coloque os arquivos dentro de outra pasta.
Depois vá em Settings > Pages > Deploy from a branch > main > /(root).
